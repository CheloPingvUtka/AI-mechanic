# Цифровой механик — Frontend

React + TypeScript + Vite, Recharts, Lucide, i18next. Все данные и ответы приходят из backend (`/api/v1`), моков во фронтенде нет.

## Запуск

Нужен Node.js 20.19+ или 22.12+ и запущенный backend на `http://127.0.0.1:8000` (см. `backend/README.md`).

```powershell
npm install
npm run dev
```

Открыть http://localhost:5173. Vite проксирует `/api` на backend (`vite.config.ts`), поэтому с телефона в той же сети страница открывается по `http://<IP компьютера>:5173` без настройки CORS. Другой адрес backend — `VITE_API_URL` в `.env` (см. `.env.example`).

## Страницы

- `/` — **мастер для механика**: 4 крупных шага (машина → результат → работа → заявка), кнопки под перчатки, голос. Вердикт одной фразой; рабочий план приходит в фоне: сначала что подготовить (предварительно), потом шаги из руководства с рисунком страницы, нормой и полем замера; новое подсвечивается. Чат с агентом — в боковой панели («Спросить ИИ»).
- `/detail` — всё на одном экране (для ПК и главного механика): вердикт, план, история anomaly_score (B2), чат.
- `/fleet` — режим главного механика (B3): норма / внимание / карантин, фильтр, история, переход в мастер.
- `/tickets` — заявки, созданные агентом с момента запуска backend.

Общее:

- **Ход работы агента** виден вживую (что ищет, какие страницы нашёл, проверка чисел) и остаётся свёрнутым под ответом.
- **Источники** — карточки с рисунком страницы; ссылки «📖 руководство, стр.» в тексте кликабельны; просмотр страницы во весь экран, «PDF на этой странице», официальный сайт производителя.
- **Фото**: кнопка камеры в чате, фото сжимается на устройстве; агент сравнивает его с рисунками руководства (вывод — гипотеза).
- **Голос**: кнопка микрофона (фраза до паузы) и режим «Без рук» (слушает постоянно, не слышит сам себя). Команды на RU/UZ/KO: дальше, назад, готово, повтори, результат, заявка, подтверждаю, стоп; число — замер на текущем шаге (на экране машин — цифры госномера); остальное — вопрос агенту, ответ зачитывается. Микрофон браузер даёт только на HTTPS или localhost: для телефона запускайте `HTTPS=1 npm run dev` (самоподписанный сертификат, предупреждение принять один раз) и откройте `https://<IP компьютера>:5173`.
- **Языки**: RU / UZ (латиница) / 한국어; выбор запоминается на устройстве; агент отвечает на выбранном языке, цитаты руководства остаются по-русски.

## Структура

```text
src/
  app/            маршруты
  components/     оболочка, ErrorBoundary, UI: Markdown (ответ агента), ScoreChart, бейджи
  features/       diagnostics (механик), fleet (главный механик), tickets
  lib/api.ts      клиент backend и подписи
  types/domain.ts контракты API
```
